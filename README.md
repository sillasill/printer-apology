# The Printer Apology

A one-line apology note from an office printer to the people who use it — a small, deadpan confession in which the machine owns up to a very specific, very awkward printing mishap, then tries to talk its way out of it.

## Run it

Requires Node 22 or later. From the repository root:

```sh
node main.ts
```

This writes the entry (a single line, 1–120 characters) to `/output/entry.txt`, creating the directory if needed. The program is deterministic, uses only the Node standard library, and makes no network calls.
